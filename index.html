Connect to Firebase

This app syncs live across all devices using Firebase Realtime Database (free).
Paste your Firebase project config below — this only needs to be done once.

Quick setup (5 min):
1. Go to console.firebase.google.com
2. Create a project → Realtime Database → Create Database → Test mode
3. ⚙ Project settings → Your apps → </> Web app → copy config
4. Paste each field below and click Connect

Your config is saved locally on this device. All devices using the same Database URL will sync instantly.
